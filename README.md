hmt-watch: pushes an ntfy alert (topic in the NTFY_TOPIC secret) when any official HMT Gandaberunda variant is back in stock.
Runs on GitHub Actions every ~10 min (GitHub may delay scheduled runs). Notify-only; never logs in or buys.
Actions tab -> hmt-watch -> Run workflow (tick test) sends a test push.
Disable the workflow once you have bought the watch.
